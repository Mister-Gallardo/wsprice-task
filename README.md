# Подбор автозапчастей (Favorit Parts)

Демо: https://mister-gallardo.github.io/wsprice-task/

React, Vite, Redux Toolkit (RTK Query), Bootstrap.

## Запуск

```bash
npm install
npm run dev
```

Адрес API и ключ лежат в `.env`. Там тестовый ключ из документации; для своего ключа создайте `.env.local`.

## Как работает

1. Вводим артикул (от 3 символов, debounce 500 мс), получаем список производителей.
2. Выбираем производителя, получаем деталь с аналогами (`analogues=on`). В таблице по строке на каждый склад: производитель, наименование, склад, дата отгрузки, цена, остаток.

## Заметки

- API доступен по https и отдаёт CORS-заголовки, поэтому запросы идут из браузера напрямую. Ключ при этом попадает в бандл, для тестового ключа это допустимо; с боевым ключом запросы стоит проксировать через свой бэкенд.
- Ошибки API приходят в поле `error` (и с кодом 200, и с 403), они обрабатываются в `baseQuery` вместе с сетевыми ошибками и таймаутом.
- Если деталь не найдена, API возвращает пустую структуру, такие элементы отфильтровываются.
- Цена берётся из `warehouses[].price`, верхнеуровневый `price` по документации устаревший.
- Деплой на GitHub Pages через GitHub Actions при пуше в `main`.
